Camera denied? Recording tips and mobile setup

Important: The camera requires a secure https:// page (or another supported secure context). Opening an HTML file from Downloads or inside a preview may fail. For installable app mode, upload the complete app folder to an HTTPS host and use Add to Home Screen.

Android: Chrome → lock/site controls → Permissions → Camera and Microphone → Allow. Also enable camera permission for Chrome in Android Settings.

iPhone: Safari → aA/page settings → Website Settings → Camera & Microphone → Allow. In iPhone Settings check Safari camera permission if prompted.

Recordings: Videos are saved using the format supported by your mobile browser, commonly MP4 in Safari or WebM in Chromium. Turn off battery saver and keep the app visible. Use your phone's native camera if this browser doesn't support recording.

Privacy: No video or script is uploaded by this app. Camera and microphone are processed on your device.
